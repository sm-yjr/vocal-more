# Vocal More 0.4.11

胶囊会按实际中英文文字宽度调整布局，长文本展开后自动滚动到最新输出，录音波形和处理进度更新也减少了重复布局与无效刷新，显隐切换更稳定。

历史录音播放改为 macOS 原生 AVPlayer 直接读取 WAV/FLAC 文件。设置页只传递录音 ID 和播放状态，关闭设置窗口时会停止播放并清空待执行的 JavaScript，长录音不会再通过 base64 复制进 WebView。

本次还修复了旧播放状态残留、波形静止时的重复更新和处理进度到达目标后的定时器清理，并保留真实的原生胶囊检查与录音播放内存检查。

独立设置窗口测试进程对 20 分钟、38,400,044-byte 静音 WAV 的实测峰值从旧路径约 334 MB 降至原生播放约 62 MB；该数据不包含 ASR 或 helper 进程，也不代表整个应用总内存。
