# Vocal More 0.7.4+10

适用于 macOS 14 及以上的 Apple Silicon Mac。

- 全面重构「个人词典」设置界面为顶部共享自动学习栏加「词条库 / 学习建议 / 隐私与文件」三分段工作台，在标准与 640×480 小窗下均保持紧凑清晰。
- 词条库新增实时搜索（搜不到一键添加）、排序切换、单行快速添加（支持回车提交与同名追加别名提示）、多行批量导入、原地行内编辑（支持改名、并发冲突保护及单个别名一键删除）以及移除后 8 秒原位无损恢复。
- 自动学习建议按「待审核 / 已加入 / 处理中与历史」分层展示并修正状态机与列表截断问题：支持人类可读原因与相对时间展示、待审核项编辑后加入、以及安全清理已完结噪音历史记录。
- 隐私与文件页新增 8 个常见敏感应用快捷排除开关（与手动 Bundle ID 输入框实时共享草稿），并支持修改本地 `dictionary.yaml` 后一键严格校验重新加载。
