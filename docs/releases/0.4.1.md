# Vocal-More 0.4.1

本版本集中优化听写进入与退出速度。应用启动、模式切换和 ASR 配置刷新后，会为当前听写模式建立并保持干净的实时连接；空闲断线时自动重连，首次听写可以直接复用已完成 `session.ready` 的连接。

停止听写时取消固定 1 秒尾录等待，立即停止录音并在 finish worker 上完成 ASR 收尾。录音后端仍会排空已经进入原生转换器的音频，避免丢失已接收的尾帧。

实时音频包统一为 80ms。旧版默认的 40ms 和 100ms 配置会迁移到 80ms，减少 WebSocket 请求开销并采用三模型实测中更稳定的延迟区间。

DashScope 实时识别同时支持公共域名和工作空间专属域名。高级设置中可以切换两套 endpoint；专属地址仅接受官方 `wss://*.maas.aliyuncs.com/api-ws/v1/realtime` 格式，切换后会丢弃旧暖连接并按新配置预热。

macOS 新增可配置的原生快速粘贴。启用后直接通过 `NSPasteboard` 写入文本并使用 CoreGraphics 发送 Cmd+V，省去兼容路径的固定等待；AppKit 或事件创建不可用时自动回退到原有的 pyperclip 与 pynput 路径。
