## 更轻的后台运行与安装包

- 停止录音后短暂保留已初始化的 Apple VoiceProcessingIO 和 ASR 工作线程，空闲超时后自动释放，兼顾亚秒级重复启动和长期后台资源占用。
- 关闭设置窗口时主动拆除 WebView、消息处理器与页面资源，减少窗口关闭后的残留内存和 CPU 活动。
- 移除生产环境中的 OpenAI Python SDK，改用轻量的 OpenAI-compatible HTTP 客户端；保留超时、错误解析与响应格式兼容性。
- 移除运行时 NumPy 依赖，音频回调改为无 NumPy 的缓冲区处理；主力 macOS 原生采集路径保持不变。
- 固定并裁剪 DashScope 运行时资源，排除应用不使用的 tokenizer、缓存、测试包和基准模块。
- macOS 打包现在严格从 `uv.lock` 安装生产依赖，避免构建环境漂移。

## 性能与验证

- 完整 Python 测试套件：810 项通过。
- 新构建应用体积由 0.3.16 的约 83,384 KiB 降至约 45,564 KiB，减少约 45.4%。
- 音频采集模块导入后的常驻内存由约 42.1 MiB 降至约 37.8 MiB。
- MacBook Pro 内建麦克风连续 50 次暖启动：0.3.16 中位数 185.7 ms、p95 194.5 ms；0.3.17 中位数 185.6 ms、p95 194.6 ms，未观察到基线退化。
- 原生音频库编译、隔离应用导入与生产依赖裁剪检查通过；应用包内不再包含 OpenAI SDK 或 NumPy。
