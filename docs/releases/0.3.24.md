# Vocal-More 0.3.24

本版本修复录音结束时尾音容易丢失，以及使用 Qwen Audio 3.0 Realtime Plus 对讲时 CPU 占用异常升高的问题。

## 修复内容

- 用户结束语音或录音后，录音流会继续接收最多 1 秒的尾部音频，再执行实际停止和提交，减少最后几个字被截断的情况；取消操作仍可立即中断等待。
- Qwen Audio 3.0 Realtime Plus 的实时音频发送改为合并为约 100 ms 的帧，减少 Base64、JSON 和 WebSocket 调度开销。
- 对高通滤波路径进行向量化处理，避免逐采样 Python 循环造成的高 CPU 占用。
- 原生实时链路在请求响应时明确使用文本输出，并丢弃无需处理的音频事件，降低回调队列和调试追踪的负载。
