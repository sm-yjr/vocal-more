# Vocal-More 0.4.2

本版本围绕「边说边出字」与「交付可靠」展开，同时把低语输入的调参体验升级为可验证的校准流程。

长听写模式新增分段粘贴（默认关闭，可在设置-常规开启）。录音过程中，已定稿的语音分段会实时粘贴到目标应用，不再等整段结束；启用后该次听写跳过润色，直接交付未润色文本。分段粘贴仅在长听写普通听写场景生效，指令模式、按住说话、会议模式与 inline 润色模型不受影响。

设置-音频页新增低语校准向导。用户先保持安静约 3 秒测量噪声底，再轻声读一句测试语测量低语电平，应用据此推荐增益与波形满幅参数，确认后一键应用。推荐算法保守取值：目标电平 −14 dBFS，宁欠增益不削波，软限幅保持开启；样本不足或信噪比不足时提示重试。

润色新增输出语言选项（保持原语言 / 统一为中文 / 统一为英文），说中文可直接产出英文文本。翻译要求同时作用于独立润色与 Omni inline 润色两条链路；专有名词、代码、命令与用户词典术语保持原样不翻译。macOS 与 Windows 设置界面均可配置。

新增确定性双语文本格式化：在词典归一化之后、粘贴之前，本地补齐中文与英文/数字之间的半角空格，把全角字母数字转为半角，并压缩重复的中文句末标点。URL、路径与行内代码原样保留；该处理不依赖 LLM，关闭润色时同样生效。

自动粘贴新增剪贴板保护（默认开启）。粘贴前快照剪贴板文本，粘贴完成约 1 秒后自动恢复；若期间剪贴板被其他应用写入则放弃恢复，绝不覆盖他人内容。原生快速粘贴与兼容路径均已覆盖。

菜单栏新增「复制最近结果」。粘错窗口或粘贴失败时，可直接从菜单栏取回最近一次听写或指令的完整文本，无需打开设置翻历史；菜单不展示文本内容，保持既有隐私边界。

录音持久化移出收尾关键路径：停止录音后，WAV 写盘与索引同步改为与 ASR 网络定稿并行执行，缩短从松开按键到文字出现的等待，长录音收益更明显。
