# Vocal More 0.5.0a5

这是 0.5 系列的第五个 alpha 预发布，新增 Qwen3.8 Omni Flash Realtime 听写模型并接入其官方定价。

## 新增

- 听写模型选择新增 Qwen3.8 Omni Flash Realtime，排在可选列表首位。经真实音频端到端验证，转写完整准确；输入音频单价约为 Qwen3.5 Omni Flash Realtime 的 22%。
- 长音频离线降级自动路由到 `qwen3.8-omni-flash`（已实测可用），沿用既有的按模型后缀推导规则。
- 费用估算接入 2026-09-21 核对的华北 2（北京）官方原价：realtime 输入音频 6 元/百万 Token，离线版输入不分模态 0.8 元/百万 Token。

## 说明

- 服务端 `session.created` 默认 voice `Chelsie` 提交音频会被拒，本版沿用 Omni realtime 系列既有的显式 `voice="Tina"`，无需用户配置。
- 默认听写模型仍为 Qwen3.5 Omni Flash Realtime，避免改变既有配置行为；可在设置中手动切换新模型。
- Qwen3.8 Omni Plus Realtime 服务端尚未开放（握手后即被断开），暂不加入目录。

本版继续使用 Rust 业务后端与 Python/PyObjC 薄 UI，GPUI 前端迁移尚未完成。属于 Nightly/alpha 通道，不替换 Latest stable。GPL-3.0-only 许可保持不变。
