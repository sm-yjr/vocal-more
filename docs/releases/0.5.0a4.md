# Vocal More 0.5.0a4

这是 0.5 系列的第四个 alpha 预发布，改进听写反馈、首次设置引导、快捷键录制和历史记录复制，并补齐 Rust 后端薄 UI 的对应交互。

## 改进

- 听写失败时在胶囊中短暂显示原因，保留可操作的连接失败与麦克风恢复提示；录音期间可按 Esc 取消。
- 自动粘贴模式减少成功通知打扰，旧 Python 运行路径在仅复制到剪贴板时仍显示结果提示。
- 首次设置支持跳过，并保留未完成标记；重新运行引导需要确认，跳过时停止正在进行的麦克风试录。
- 引导页和音频页提供麦克风系统权限设置入口。
- 快捷键录制支持 Esc 取消，裸修饰键需再次按下确认，避免误录。
- 历史记录复制优先使用 Clipboard API，保留 WebView 兼容回退，并显示真实的成功或失败状态；完善中英文文案。

## 修复

- 配置更新失败会在设置中显示错误并按宿主状态回退控件，引导页也能看到错误反馈。
- 补齐跳过引导标记的桥接校验、Rust 配置解析与持久化，避免重新打开设置后状态丢失。
- 修复复制兼容回退抛错时临时文本框残留和焦点丢失。

本版继续使用 Rust 业务后端与 Python/PyObjC 薄 UI，GPUI 前端迁移尚未完成。属于 Nightly/alpha 通道，不替换 Latest stable。GPL-3.0-only 许可保持不变。
