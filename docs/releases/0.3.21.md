## 录音兼容回退路径性能热补丁

- 优化 PortAudio/Python 兼容音频回调中的 DSP 处理，将逐采样的增益、软限幅、RMS 计算和 PCM 编码改为 NumPy 批量运算。
- 减少录音回调中的 Python 对象分配，降低高增益、高清滤波和软限幅配置下的 CPU 占用，缓解长时间录音时单线程占用过高的问题。
- 将 NumPy 从开发依赖移入运行时依赖，确保兼容回退路径在正式应用环境中可用。

## 验证

- Python 全量测试：825 项通过，1 项按平台跳过。
- 前端测试：42 项通过；TypeScript 类型检查、ESLint 和原生音频库编译通过。
- 80 秒兼容回调 CPU 基准：单核占用由 0.51% 降至 0.17%，约降低 67%。
- 新增回归测试，确认兼容回调不再调用逐采样的 Python `math.tanh`。
