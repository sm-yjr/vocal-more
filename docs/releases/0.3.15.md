## 麦克风启动 Hotfix

- 修复原生音频消费线程与停止流程的锁竞争，避免旧 VoiceProcessingIO 会话延迟释放后导致后续录音连续启动失败。
- 将 Core Audio 启动保护时限调整为 3 秒，避免 Studio Display 等正常但较慢的路由被误判为卡死。
- Studio Display 恢复使用低延迟 CoreAudio 兼容路径，实机连续 8 次启动全部成功，首帧稳定在约 580–595 ms；此前 VoiceProcessingIO 首帧约需 1.3–1.7 秒。
- Mac 内建麦克风继续使用 Apple Voice Processing 与 AGC；应用空闲时不会持续占用麦克风来隐藏启动成本。
