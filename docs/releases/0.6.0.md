# Vocal More 0.6.0

0.6.0 是 Rust 桌面端的首个正式版，面向 macOS 14 及以上的 Apple Silicon Mac。

## 变更

- macOS 应用改为 Rust 桌面程序：设置页使用 GPUI Kit，悬浮胶囊、菜单栏、快捷键、粘贴、屏幕上下文、播放与 Sparkle 更新由原生 AppKit 适配器实现，并直接内嵌 Rust 业务后端。安装包不再包含 Python、PyObjC 或 WebView 前端。
- 保留现有 Objective-C++ 原生音频库及低声输入链路（高增益、高通滤波、软限幅与噪声门）。
- 设置窗口改为 Vercel Geist 风格，跟随系统浅色/深色外观；状态以徽标显示，按钮、说明文字和分区标题统一排版。
- 菜单栏重新分组为“录音”和“文字”，用词与设置窗口一致；没有可复制的结果时“复制最近结果”不可用。
- 修复 macOS 27 上打开设置窗口时崩溃的问题。
- 退出时等待已接受的设置与词典修改写入完成；无法保存时给出提示。
- 流式免提模式连续回填多段文字时，恢复的是用户原有剪贴板内容，而不是上一段转写文字。
- 屏幕上下文截图在一帧丢失后可自动恢复，不再需要重启应用。

## 版本与更新通道

- 版本号改为 `x.y.z+构建号`，本版为 `0.6.0+1`。alpha 通道停用，仅保留 beta。
- 更新通道改为 Stable / Beta：Stable 只接收正式版本；Beta 同时接收 beta 和正式版本，以较新的为准。
- 已安装的 alpha（包括 0.6.0 alpha 1）会直接升级到本版正式版，之后跟随 Stable。
