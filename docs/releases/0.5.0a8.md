# Vocal More 0.5.0a8

这是 0.5 系列的第八个 alpha 预发布，把“看屏幕说话”从一次性模式整理为可持久配置的屏幕上下文开关。

## 新增

- 设置 → 通用新增“看屏幕说话”开关，关闭时维持纯音频听写；开启后，每次听写会按会话生命周期向 Qwen3.8 Omni Flash Realtime 发送屏幕帧。
- 屏幕上下文开关默认关闭，可从菜单栏快速查看和切换。启用时仍会先启动音频听写，再异步申请屏幕录制权限和发送首帧，避免权限弹窗丢失开头语音。
- 启用屏幕上下文时会话临时使用 Qwen3.8 Omni Flash Realtime，保存的默认听写模型不会被改写；关闭开关后后续会话恢复用户选择的模型。

## 隐私与边界

- 屏幕帧只在启用开关的当前听写中保留于内存并发送给实时模型，不写入录音历史、历史仓储或诊断日志；听写结束后到达的旧帧会被丢弃。
- 首次使用需要 macOS 屏幕录制权限。未配置 Qwen3.8 Realtime 所需的 Model Studio workspace WSS endpoint 时，设置页会提示先完成该配置。
- Qwen3.8 Omni Flash Realtime 的 Realtime API 当前没有官方 `reasoning_effort` 或“思考强度”参数，因此本版未添加会产生误导的思考强度滑块。

本版继续使用 Rust 业务后端与 Python/PyObjC 薄 UI，GPUI 前端迁移尚未完成。属于 Nightly/alpha 通道，不替换 Latest stable。GPL-3.0-only 许可保持不变。
