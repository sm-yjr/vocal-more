# Vocal More 0.7.0+5

本版对 macOS 桌面端进行了全链路 UI/UX 重新设计（主窗口、悬浮胶囊与菜单栏），以「开箱即用 + 渐进披露」为核心理念，适用于 macOS 14 及以上的 Apple Silicon Mac。

## 变更

- **全新主窗口工作台（7 项分组导航）**：侧边栏划分为「工作区（概览 / 录音历史 / 个人词典）」与「设置（声音与低声 / 识别与润色 / 快捷键与输入 / 通用与连接）」，支持待审核学习词条数角标与环境就绪状态提示。
- **概览页与 3 步聚焦式首次引导**：集中展示系统就绪清单、声音场景 / 智能润色 / 看屏幕说话快捷切换、当前激活的听写场景及最近转写；首次引导改为「1. 连接服务 → 2. 系统权限 → 3. 低声体验」三步聚焦流程，可随时跳过或继续。
- **声音与低声体验升级**：提供「办公室低声（推荐）」「正常说话」「嘈杂环境」3 张场景预设卡片，整合麦克风选择与实时试音，并将 8 秒低声智能校准与高级 DSP / 诊断参数清晰分层；菜单栏同步新增「声音场景」子菜单与一键直达低声校准。
- **识别、自定义场景与润色整合**：合并原「识别」与「润色」页为「识别与润色」，保留 0.6.2 自定义听写场景并展示识别模型能力标签，新增 5 组一键润色风格预设（原话轻修 / 清晰结构化 / 技术文档 / 轻松聊天 / AI 提示词），将空间端点与 5 类自定义提示词折叠为按区展开的高级面板。
- **内容优先的录音历史与个人词典**：录音历史改为单栏内容流，支持按「全部 / 失败 / 会议」筛选、单行存储与费用摘要、5 秒撤销删除与可展开会议纪要；个人词典将待确认自动学习建议提升到页面顶部。
- **悬浮胶囊交互增强**：支持底部居中、顶部居中及记住免提拖拽位置（多屏自动防裁切，可在设置中一键重置），放大红/绿取消与完成按钮至 26×26pt，新增免提录音计时器与 3 秒琥珀色润色回退提示。

## 验证范围

已完成 Rust 全工作区测试（`vocal-more-backend`、`vocal-more-core`、`vocal-more-desktop`）、Clippy 零警告检查、Python 回归测试以及 GPUI Kit 0.9.1 真实 Metal 渲染验收（115 张截图，覆盖 7 标签与首次引导、中英双语、浅/深外观、900×740 与 640×480 窄窗、36 项配置字段、7 项复合配置、自定义听写场景与低声校准）。

本版为 stable，版本与构建号为 0.7.0+5。
