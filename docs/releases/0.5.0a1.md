# Vocal More 0.5.0a1

这是 0.5 系列的首个 alpha 预发布，面向 macOS 14 及以上的 Apple Silicon Mac。安装包默认使用 Rust 业务后端，保留现有菜单栏、悬浮胶囊、设置界面及原生音频处理；GPUI 前端迁移尚未包含在本版中。

## 主要变化

- 将录音会话、识别与润色请求、配置、词典、历史和计费逻辑迁移到独立 Rust 后端，通过有界消息通道与界面协作。
- 改善麦克风启动与首块音频接收，复用现有低声输入 DSP，保留增益、高通、限幅和噪声门能力。
- 缩短录音开始反馈和停止后的本地处理等待，合并 UI 唤醒及管道读取，降低常驻内存与录音处理 CPU 开销。
- 自动在空闲时压缩历史录音，保留最近 3 条 WAV；压缩后校验完整 PCM，转换失败时保留原音频。历史提交失败或录音取消时不会发布成功结果。

同机本地测试中，Rust 版本优化前后的开始反馈中位数从 15.94 ms 降至 0.86 ms，收尾从 115.48 ms 降至 50.72 ms。薄 UI 加后端的空闲内存为 36.03 MiB，对照 Python 为 63.00 MiB。这些是合成音频、本地服务及指定窗口场景下的测量，不代表所有设备、云服务或指标均优于 Python。测试口径、逐轮数据和剩余差距见仓库的性能报告。

## Alpha 使用说明

- 本版属于独立 alpha 更新通道，不会推送给稳定版用户。安装 alpha DMG 切换到该通道，安装稳定版 DMG 可切回稳定通道；两个通道使用相同应用标识，会替换同名应用。
- Rust 首次启动会把原 Python 的配置、词典、录音和学习数据库复制到 `~/.vocal-more/rust-backend`，保留原数据。之后两套数据独立保存，不会自动双向同步；切回 Python 稳定版时，alpha 中的新录音和设置不会自动带回。
- 可通过菜单手动检查更新；Rust 界面的启动自动检查更新尚未恢复。
- 快速连续录音时，上次尚未执行的粘贴可能被下一次录音清除；流式粘贴失败后的全文补贴仍需完善。遇到文字未插入，可从“复制上次结果”或历史记录取回结果。
- 实时网络重试、失效输入设备自动回退和完成通知仍与 Python 版本有差异。网络异常时可重新录音，输入设备失效时请在设置中重新选择。
- 本版未完成真实蓝牙热插拔、睡眠唤醒及所有目标应用粘贴场景的完整验收。Windows Rust 桌面安装包不在本次发布范围内。

GPL-3.0-only 许可保持不变。
