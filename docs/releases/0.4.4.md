# Vocal More 0.4.4

本版本修复提示词模式在真实使用中暴露的输出边界与悬浮胶囊可读性问题，仅以 macOS 作为测试和发布目标。

提示词编译器不再复用普通听写润色的内部上下文。用户词典与 ASR 校准内容、前景 App 粗粒度类别、润色强度、语气、人设和结构化格式设置不会再发送给提示词编译链路，也不会出现在最终 Prompt 中。词典仍用于识别与术语归一化，但不再作为可见任务上下文。

最终 Prompt 不再包含 `Open questions`、待确认信息或 Stop rules。录音期间识别到的高价值信息缺口继续通过悬浮胶囊直接向用户提问；用户停止录音后，编译器只整理已经提供的信息，缺失字段直接省略，不使用占位符或推测补全。

新增确定性的 Prompt 输出清洗边界。即使模型偶发复述内部规则，也会在粘贴前移除未解决问题章节、终端场景提示、格式保护说明、词典修正表和其他内部控制文本，同时保留用户真正说出的业务约束。

悬浮胶囊在显示补充问题时会动态扩展，支持多行与换行文本，不再使用单行省略号截断。提示清空或开始下一次录音时恢复紧凑尺寸，避免长期遮挡当前应用。
