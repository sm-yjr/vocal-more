# Vocal More 0.7.1+7

本版聚焦**听写准确率、低声抗噪与中英双语保真**全面升级，并完善主窗口、设置页与菜单栏的产品化体验，适用于 macOS 14 及以上的 Apple Silicon Mac。

## 变更

- **双轨听写模型与多语种保真升级**：
  - 接入百炼最新 `qwen-audio-3.1-asr-flash-message`（默认实时模型）、`qwen-audio-3.1-asr-flash-streaming`、`qwen-audio-3.1-asr-flash`（默认短音频离线降级）、`qwen-audio-3.1-realtime-plus` / `flash`，以及 `qwen3.8-flash`（默认文本润色模型）/ `qwen3.8-max`，同步更新北京区官方计费快照。
  - 实现 `hybrid_asr` 双轨路由：默认「原话轻修」直走 3.1 输入法模型原生口语顺滑（`disfluency_removal_enabled`）单级极速直出；切换结构化、技术文档、聊天、AI 提示词或翻译等高级风格时自动级联二阶段文本润色模型；开启「看屏幕说话」时自动路由至 `qwen3.8-omni-flash-realtime` 并在关闭后自动恢复原模型。
  - 修复双语听写润色 Prompt 的中文偏置，强化原语种保真约束，避免纯英文或中英混说被静默翻译为中文。
- **听写前光标上下文、动态超级热词与跨轮短记忆**：
  - 新增默认开启的「光标上下文与动态热词」（`cursor_context_enabled`）：听写启动时并发采集聚焦应用、窗口标题、选中文本及光标前后语境，不阻塞热键启动，晚于握手返回时通过 `continue-task` 会话中热更新；兼容无 `AXSubrole` 的主流编辑器与浏览器文本区，同时对密码/安全输入框、隐私排除应用及 IPC 异常严格 fail-closed。
  - 自动提取光标附近的代码与专有标识符，与个人词典共同以 3.1 ASR 超级热词（`weight=50`）增强识别；保留同应用 5 分钟内最近 3 轮听写记录写入多轮 `input.context`，并在关闭开关或更新隐私排除应用时即时清空缓存。
- **低声 DSP 管线升级与松手尾音宽限**：
  - 原生音频引擎将 1 阶 RC 高通升级为 4 阶 Butterworth 级联双二阶高通（-24 dB/oct 滚降），更彻底抑制风扇、空调等低频底噪，并接入低声动态压缩与软拐点峰值限幅，放大气声的同时抑制喷麦失真。
  - 新增可配置松键尾音宽限（`audio.tail_padding_ms`，默认 `200` ms，范围 `0–500` ms），避免松开快捷键吞掉句末尾字，取消听写时立即撤销。
- **界面与菜单栏产品化完善**：
  - 概览页与识别润色页实时展示当前双轨执行路径（原生单级顺滑 vs 级联二阶段润色）、「看屏幕说话」自动路由说明与辅助功能权限内联一键引导；模型规格区新增超级热词与原生口语顺滑能力展示。
  - 菜单栏「文字」分组新增一键开关 **光标上下文**；声音与低声页高级摘要同步展示 4 阶高通、动态限幅与尾音宽限。
