# Vocal More 0.5.0a6

这是 0.5 系列的第六个 alpha 预发布，补齐 Qwen3.8 Omni Flash Realtime 在 Rust 后端的接入，修复 0.5.0a5 只更新 Python 侧导致新模型不出现在设置页的问题。

## 修复

- Rust 后端重新生成产品契约（模型目录、定价、会话固件），设置页模型列表现在包含 Qwen3.8 Omni Flash Realtime。
- 实时协议层此前硬编码仅允许 Qwen 3.5 Omni Realtime，会直接拒绝 Qwen3.8；现已放行 `qwen3.8-omni-flash-realtime`。
- 实时流上下文时长保护覆盖 Qwen3.8 前缀，上限对齐官方 600 秒累计音频历史（Qwen3.5 Flash 保持 480 秒）。
- 模型集成测试的计数断言改为从产品契约动态推导，后续新增模型不再需要逐个改断言。

## 说明

0.5.0a5 已把 Qwen3.8 Omni Flash Realtime 加入 Python 侧目录与定价，但其架构下设置页与听写链路由 Rust 后端提供，因此 a5 的用户实际看不到也用不了新模型；本版修复该缺口。默认听写模型仍为 Qwen3.5 Omni Flash Realtime。

本版继续使用 Rust 业务后端与 Python/PyObjC 薄 UI，GPUI 前端迁移尚未完成。属于 Nightly/alpha 通道，不替换 Latest stable。GPL-3.0-only 许可保持不变。
