# Vocal More 0.4.16

本版本统一了各个润色档位的口语清理行为：会清除无意义的口头词和口吃重复，并在出现自我纠正时采用明确的最终说法。润色仍按当前档位工作，输入用途、输出语言和其他设置说明同步更新。

自动词典学习改为更严格的专名和技术术语候选验证。候选必须通过完整的编辑映射检查，模型 confidence 只用于诊断；大小写纠正或系统精确同音匹配可以快速学习，其他候选需要来自两次独立听写的重复确认。同一录音最多贡献一次确认，确认会持久保存到 SQLite，重复录音不会重复计数；冲突映射和已撤销映射不会自动加入。已有词典条目继续保留。这些规则用于减少误收，不能保证消除所有模型判断错误。

本版本修复短词过滤、下一次粘贴开始前的学习边界保存，以及包含 emoji 时 Accessibility UTF-16 选区换算造成的错位。录音展开胶囊面板宽度从 400pt 调整为 360pt，可见展开高度从 360pt 调整为 320pt，波形区域从 274pt 调整为 234pt；前端设置 policy 文案和构建资源同步更新。

GPL-3.0-only 许可保持不变。
