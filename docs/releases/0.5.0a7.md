# Vocal More 0.5.0a7

这是 0.5 系列的第七个 alpha 预发布，扩展 Qwen3.8 Omni Flash Realtime 的语义听写能力，并加入显式的“看屏幕说话”和长会话自动续接。

## 新增

- Qwen3.8 Omni Flash Realtime 由主模型直接负责最终听写，即使关闭可选的润色开关也会请求语义转写；这条链路面向口音和非标准发音的联合理解。`gummy-realtime-v1` 旁路结果继续用于流式反馈、诊断和恢复，不绕过主模型作为最终结果。
- 模型能力展示补充 74 种语言、39 种中文方言、输入 Token/音频上下文容量和自动续接信息。
- 菜单栏新增“看屏幕说话”。这是一次显式、单次听写的屏幕上下文授权：macOS 主显示器在内存中缩放到最高 720p 并编码为不超过 190 KiB 的 JPEG，首个音频块后发送，录音期间约每 2 秒更新一帧，接近服务端视频上限时停止发送。屏幕内容只用于识别界面文本、代码和专有名词，模型仍只输出用户所说内容，不描述或复述屏幕。
- Qwen3.8 实时听写在累计 540 秒时主动提交当前段并建立下一会话。本地录音保持连续，音频与文本按段序合并；新会话使用独立的有界输入队列，避免触碰服务端 600 秒/100 轮音频历史限制。

## 隐私与边界

- 屏幕帧只在本次显式启用的听写中保留于内存并发送给实时模型，不写入录音历史、历史仓储或诊断日志；听写结束后到达的旧帧会被丢弃。首次使用需要 macOS 屏幕录制权限。
- 一次听写不会复用其他听写的屏幕内容或对话历史；屏幕上下文仅对 Qwen3.8 Omni Flash Realtime 生效，音频采集不会因视觉帧队列满而阻塞或降级。

本版继续使用 Rust 业务后端与 Python/PyObjC 薄 UI，GPUI 前端迁移尚未完成。属于 Nightly/alpha 通道，不替换 Latest stable。GPL-3.0-only 许可保持不变。
