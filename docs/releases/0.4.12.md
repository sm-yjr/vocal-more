# Vocal More 0.4.12

本版本整理了当前工作区中已完成的听写模型、运行时和诊断改动。设置页现在按通信协议和输出能力展示实时听写模型：原生 ASR、实时内联生成与级联链路分开标识，专用实时 ASR 排在推荐位置，已下架的模型仍可用于读取旧配置和历史任务。历史的独立语音指令路由、App 上下文个性化和会议记录生成入口已移除，普通听写与 Prompt 输出继续沿用现有设置。

听写启动链路增加了有界的启动诊断，支持在故障时记录热键、ASR、音频启动阶段和首个 PCM 的关联信息，并在支持包中以脱敏形式导出。Apple VoiceProcessingIO 增加了可选的预初始化 C ABI：待机期间只准备音频图，不安装采集 tap、不启动采集线程，也不持续读取麦克风；开始听写时复用准备好的图，空闲复用窗口延长到 30 分钟。没有该可选符号的旧原生库仍走普通启动路径。Studio Display 实测冷启动首个 PCM 约 1457ms，预初始化后完整 AudioRecorder 首个 PCM 约 613ms/608ms，AGC 状态验证通过。

同时更新了低声场景下的音频启动与复用保护、模型词典语料注入、设置页与历史录音状态、并发运行模型和 Windows 文档，并补充模型目录、后端范围、Rust UI 可行性、启动诊断测试以及现有本地分析可视化文件。GPL-3.0-only 许可保持不变。
