# Vocal More 0.5.0a2

这是 0.5 系列的第二个 alpha 预发布，修复 0.5.0a1 在 macOS 上完成听写并准备粘贴结果时可能直接退出的问题。

## 修复

- 将 Rust 薄 UI 的最终粘贴投递切回 AppKit 主队列，避免从后台 platform executor 构造 `pynput.keyboard.Controller` 时触发 HIToolbox 队列断言。
- 明确启用 macOS native fast paste 时延迟创建 `pynput` Controller；原生剪贴板与 Quartz 投递成功时不再初始化兼容键盘路径。
- 保留 native fast paste 失败后的兼容回退，并确保回退所需的输入源查询也发生在主线程。

本版沿用 0.5 alpha 独立更新通道以及 0.5.0a1 的 Rust 后端、数据迁移和回退边界。GPL-3.0-only 许可保持不变。
