# Vocal-More 0.3.25

This hotfix prevents automatic dictionary learning from running an
uninterruptible, quadratic `SequenceMatcher` diff over very long editor
AXValue snapshots, which could pin one CPU core at 100% during intercom use.

Editor text exceeding 8,000 characters is now safely skipped before the
expensive diff, while normal short-text dictionary learning remains enabled.
Candidate extraction also uses the bounded diff path so routine corrections
continue to be learned without the long-document CPU spike.
