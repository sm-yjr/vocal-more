# Vocal More 0.6.0 alpha 1

## 变更

- macOS 应用改为 Rust 桌面程序：设置页使用 GPUI Kit，悬浮胶囊、菜单栏、快捷键、粘贴、屏幕上下文、播放与 Sparkle 更新由原生 AppKit 适配器实现，并直接内嵌 Rust 业务后端。安装包不再包含 Python、PyObjC 或 WebView 前端。
- 保留现有 Objective-C++ 原生音频库及低声输入链路（高增益、高通滤波、软限幅与噪声门）。
- 退出时等待已接受的设置与词典修改写入完成；无法保存时给出提示。
- 流式免提模式连续回填多段文字时，恢复的是用户原有剪贴板内容，而不是上一段转写文字。
- 屏幕上下文截图在一帧丢失后可自动恢复，不再需要重启应用。

## 已知限制

- 这是 Rust 桌面端的首个 Nightly 版本。真实设备上的快捷键、跨应用回填、中文输入法、Spaces/多显示器及从旧版升级等场景仍在验收中，请在遇到问题时反馈。
