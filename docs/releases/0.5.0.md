# Vocal More 0.5.0

0.5.0 是采用 Rust 业务后端的首个正式版本，面向 macOS 14 及以上的 Apple Silicon Mac。它保留现有菜单栏、悬浮胶囊、设置界面与原生低声输入能力，包含 0.5.0 alpha 系列审查并验证的修复。

## 主要变化

- 录音会话、识别与润色、配置、词典、历史记录等业务由 Rust 后端承载；界面继续使用现有 Python/PyObjC 实现，GPUI 前端不包含在本版本中。
- 增加持久化的“看屏幕说话”开关，默认关闭。开启后，当前听写会使用 Qwen3.8 Omni Flash Realtime 接收屏幕上下文，结束后不保留截图；需要屏幕录制权限及对应的 Model Studio workspace WSS endpoint。
- 支持 Qwen3.8 Omni Flash Realtime 语义听写与长会话自动续接。屏幕开关不会改写保存的默认听写模型。
- 设置中可选择 Stable / Nightly 更新渠道，并支持 HTTP、SOCKS5 应用代理。
- 修复取消后旧文本回填或覆盖剪贴板、旧屏幕帧进入新会话、网络拥塞时截图阻塞录音、异常未完成录音阻止启动、IPv6 代理连接与保存、截断响应误判成功、空润色覆盖原文等问题。

## 升级与数据

首次从 Python 版升级时，会把配置、词典、录音和学习数据库复制到 `~/.vocal-more/rust-backend`，并保留旧文件。已有 0.5 alpha 用户继续使用现有 Rust 数据；两套数据不会自动双向同步。回退到旧 Python 版时，0.5 中新增的录音或设置不会自动带回。

本版进入 Stable 更新源并设为 GitHub Latest；alpha9 保留在 Nightly/alpha 更新源。两个安装包使用相同应用标识，安装时会替换同名应用；显式选择过的更新渠道仍以用户设置为准。

GPL-3.0-only 许可保持不变。本次发行不包含 Windows Rust 桌面安装包；自动化与隔离 UI 验证不代表真实设备和全部云端/目标应用场景已完成端到端验收。
