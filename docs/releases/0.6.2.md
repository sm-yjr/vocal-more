# Vocal More 0.6.2+4

本版为 macOS 桌面端新增自定义听写场景，适用于 macOS 14 及以上的 Apple Silicon Mac。

## 变更

- 在「设置 → 识别 → 自定义场景」创建、编辑和删除场景，预先保存游戏、工作或其他听写语境。
- 从菜单栏「听写场景」快速切换，也可以选择「无场景」。选中的描述会随下次听写请求发送给识别服务。
- 场景描述参与实时听写及当次录音的回退转写，关闭润色时同样生效。录音途中切换场景从下一次听写开始生效。
- 场景名称最多 60 个字符，描述最多 400 个字符；删除当前场景后自动回到「无场景」。
- 桌面组件依赖固定为 GPUI Kit 0.9.1。

## 验证范围

已完成 Rust 和 Python 自动回归、原生设置窗口操作及配置持久化验证。使用 Studio Display 麦克风采集同一段包含「杰洛特、史凯利杰、昆特牌」的录音，在百炼 Qwen3.8 Omni Flash Realtime 上对比场景开启与关闭，两组返回相同文本。场景效果取决于模型与音频内容。

开发版使用独立的应用标识；macOS 麦克风及辅助功能权限需要对相应应用授权。正式分发包通过发布 CI 完成 Developer ID 签名、公证、stapling 及更新源验证。

本版为 stable，版本与构建号为 0.6.2+4。
