# Vocal More 0.5.0a9

这是 0.5 系列的第九个 alpha 预发布，作为 alpha9 发布候选，集中修复 Rust 后端与 Python/PyObjC 薄 UI 之间已复现的会话边界、网络响应、录音恢复和设置交互问题。

## 修复

- **取消后的文本交付**：为排队文本增加 UI 取消代次和会话 generation 校验，避免取消后旧文本回填，或在关闭自动粘贴时覆盖剪贴板；手动历史复制仍可用。
- **屏幕帧会话隔离**：将初始截图绑定原始启动请求、周期截图绑定对应 generation；旧会话的成功与失败结果均丢弃，并为被占用的新会话补采截图。
- **截图与 PCM 并发**：截图发送改为非阻塞、尽力投递，避免网络队列满时阻塞 PCM 消费而截断录音；音频传输失败仍会明确上报。
- **异常录音恢复**：崩溃或磁盘写入中断留下的空或截断 WAV header 会原字节保存在录音目录的 `.recovery-quarantine`，健康记录继续恢复，避免后续启动被损坏文件阻断。
- **代理地址兼容**：分开处理 URL 主机和 socket 主机格式，修复 IPv6 代理重复方括号与重启失效，并支持规范化后的 HTTP 默认端口；覆盖 IPv4/IPv6 HTTP CONNECT、IPv6 SOCKS5 握手和数据传输。
- **HTTP JSON 完成原因**：JSON 与 SSE 共用完成原因校验，明确拒绝 `length`/`content_filter` 截断结果，保留正常 `stop` 和既有缺省值兼容。
- **空润色结果降级**：拒绝空字符串或仅含空白的润色返回，沿用原文降级路径，避免空结果覆盖已识别文本。

本轮同时补齐 Python 类型检查导入、修正测试桩中的未定义变量，并重新生成 Rust `product-contract.json`，使其版本来源与 Python 包一致。

## 候选定位与验证边界

本版本以 `main` 上的提交作为候选来源，由 Prepare Release 先完成 CI 测试、构建、Developer ID 签名、公证与 staple、DMG/Delta 校验，再由精确候选 SHA 创建 `v0.5.0-alpha.9`。Alpha 版本属于 Nightly 通道，保持 GitHub prerelease，不替换 Latest stable。

候选审查已完成 Python 1075 项、Rust 72 项、前端 105 项测试及 Rust 1.90.0 格式化/Clippy、原生静态分析和隔离 AppKit/WKWebView 检查；详细证据见 `docs/alpha9-rc-audit-2026-09-26.md`。本说明不把这些检查等同于真实麦克风、云端模型或最终签名安装包的端到端验收；低声输入、屏幕权限、长时间云端会话和实际跨应用回填仍需在候选安装包上单独验证。

本版继续使用 Rust 业务后端与 Python/PyObjC 薄 UI，GPUI 前端迁移尚未完成。GPL-3.0-only 许可保持不变。
