## Qwen Audio 3.0 识别可靠性修复

- 修复上下文参数格式，降低新模型请求异常或没有识别结果的概率。
- 针对 macOS 音频输入，将较短的采集块合并为约 100 ms 的发送帧，并安全补齐录音末尾，避免尾音丢失。
- 当流式连接、提交或最终结果异常时，自动使用稳定模型重新识别完整录音；长录音会分段恢复，避免返回空文本。
- 改进批量回放节奏和流式会话清理，使重试及后续录音更加稳定。
