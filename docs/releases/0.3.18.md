## Qwen Audio 3.0 流式语音识别

- 新增可选模型 `qwen-audio-3.0-asr-flash-streaming`，支持实时中间结果与最终转写。
- 新增独立的 DashScope Recognition 传输适配器，以 16 kHz 单声道 PCM 二进制帧发送音频，保持约 100 ms 的现有低延迟分块。
- 接入语言提示、上下文增强、错误处理、使用量追踪、计费和完整录音重试路径。
- 现有 Qwen 3.5 Omni、旧版 Qwen3 ASR、音频处理、取消和文本润色流程保持兼容。
