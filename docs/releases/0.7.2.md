# Vocal More 0.7.2+8

本版聚焦**视觉上下文清晰度、防 AI 抢答/静音幻觉护栏与长录音无缝切段**三项关键准确率与稳定性升级，适用于 macOS 14 及以上的 Apple Silicon Mac。

## 变更

- **「看屏幕说话」活跃窗口裁剪、多屏修复与帧差分去重**：
  - 自动定位当前焦点窗口所在的显示器（修复多屏下固定截取主屏的问题），对正常尺寸的活跃窗口直接裁剪窗口区域，在同等 190 KiB JPEG 上限下让 IDE 代码与小字号术语清晰度提升 2–4 倍，并减少无关桌面隐私暴露；小弹窗自动回退为所在完整显示器。
  - 新增 16×16 感知亮度指纹帧去重：首帧必发，后续每 2 秒采样若画面未实质变化（自动忽略光标闪烁）则跳过重复上传，降低冗余视频 Token 消耗与模型干扰。
- **防 AI 抢答与短静音幻觉确定性守卫**：
  - 同时守护 Omni Realtime 内联语义输出与二阶段 LLM 润色输出：在普通听写模式下，若模型对用户口述的疑问句出现未曾说过的助手腔回复或无依据的异常扩写，自动回退到忠实转写并给出温和提示；Prompt 模式、显式翻译与强结构化模式自动豁免。
  - 拦截极短静音或误触下的典型字幕水印幻觉与超长乱编文本，防止误粘贴垃圾内容到当前文档。
- **长录音静音边界切段与重叠去重**：
  - 长录音实时分段从 510 秒起实时监测 PCM 能量，遇到 300 ms 自然停顿即平滑切段；若连续说话直至 540 秒硬边界仍无停顿，自动保留 1.5 秒音频重叠并在拼接阶段自动去除边界重复词，同时将前段末尾 200 字上下文带入后续分段以保持术语连贯。
