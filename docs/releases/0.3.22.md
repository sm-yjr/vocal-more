## macOS 热补丁：修复应用启动后的状态与设置失效

- 修复 0.3.21 将 NumPy 加入运行时依赖后，macOS py2app 配置仍排除 NumPy，导致正式应用启动后无法加载录音运行时的问题。
- 将 NumPy 正确打入应用包，恢复菜单栏状态、停止录音、更多设置和音频档位调节等依赖运行时的功能。
- 在 macOS 应用构建流程中加入成品依赖 smoke test，防止运行时依赖遗漏再次进入正式发布包。

## 验证

- Python 全量测试：826 项通过，1 项按平台跳过。
- macOS 成品应用依赖 smoke test：`Vocal More packaging smoke test passed`。
