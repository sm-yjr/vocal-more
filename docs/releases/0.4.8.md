# Vocal More 0.4.8

浮动胶囊改用原生 AppKit 视图，录音波形、处理进度、流式文本、提示词建议以及取消和完成操作保持原有功能，同时避免胶囊常驻 WebKit 辅助进程，显著降低空闲状态的内存占用。

补齐事件线程的 Objective-C 临时对象回收，以及 ASR 连接、socket 和线程的关闭生命周期，减少后台资源在停止和退出后的残留。新增 physical footprint、socket 数量、TCP 状态、线程数量和 RSS 增长基线测试，作为运行时资源回归门禁。

按前台 App 自动切换普通听写与提示词模式仍处于实验阶段，因稳定性不足，本版本保持发布关闭。应用继续使用用户在设置中选择的固定模式。
