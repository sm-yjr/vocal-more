# Vocal More 0.8.0+11

适用于 macOS 14 及以上的 Apple Silicon Mac。本版采用全新 macOS 26 Tahoe 风格全面重设计桌面端设置界面，升级为 9 页结构与原生液态玻璃体验。

## 主要变更

- **全新 9 页 macOS Tahoe 设置架构**：侧边栏升级为置顶「语音引擎」状态入口加三组彩色圆角图标导航（通用 / 音频 / 外观与胶囊 · 识别 / 润色 · 快捷键 / 词典 / 历史），支持侧栏实时搜索、顶部 `< | >` 历史前进后退与透明标题栏交通灯集成，在 `890×687` 标准窗与 `640×480` 窄窗下均保持清晰紧凑。
- **Tahoe 浅色与深色主题及材质选择**：全界面改用 macOS 系统字体、分组内嵌卡片与 Apple System Blue 控件强调色；在全新「外观与胶囊」页提供「跟随系统 / 浅色 / 深色」配色切换、「经典 / 液态玻璃」窗口材质切换、应用内「减少动态效果」（同步作用于悬浮胶囊波形）以及实时深色灵动岛胶囊预览与「顶部 / 底部 / 自定义」屏幕定位器。
- **应用图标样式与显示位置**：通用页新增 4 套应用图标（默认 / 暗夜 / 声波 / 极简）实时切换及「仅菜单栏 / 菜单栏与程序坞 / 仅程序坞」显示模式；开启程序坞模式后支持点击程序坞图标直接唤起设置，并在程序坞菜单提供「打开设置…」与「导出诊断包…」，同时在通用页顶部卡片接入 Sparkle 一键检查更新。
- **低声拾音与既有能力完整延续**：音频页突出「轻声办公 / 普通说话 / 嘈杂环境」可视化波形预设卡片与低语校准入口；完整保留 v0.7.4 个人词典三分段工作台、自定义听写场景、3.1 双轨识别、光标上下文、看屏幕说话、FLAC 无损压缩与会议纪要功能。
