## 新增 Qwen 3.7 润色模型

- 新增 `qwen3.7-plus`，适合优先追求润色质量的场景。
- 新增 `qwen3.7-flash`，适合优先追求响应速度的场景。
- 两个模型均支持可选思考模式，并使用现有润色提示词、上下文和个性化设置。
- 润色模型列表按新版本优先排列，现有 Qwen 3.6 Plus 与 Qwen 3.5 Plus 保持可用。
