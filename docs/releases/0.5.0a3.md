# Vocal More 0.5.0a3

这是 0.5 系列的第三个 alpha 预发布，增加可切换的更新渠道和应用网络代理，并改进 DashScope API Key 与模型可用性检查。

## 新增

- 在“设置 → 通用”增加 **Stable / Nightly** 更新渠道；Nightly 对应 alpha feed，可直接接收后续 alpha 自动更新。旧 Alpha 安装在没有显式配置时继续沿用 Nightly。
- 增加应用网络代理设置，支持 `http://` 和 `socks5://` 代理地址，并将代理应用于模型检查、HTTP 请求和实时 WebSocket 连接。

## 改进

- API Key 检查扩展为检测当前目录中的全部可用模型：ASR 模型通过真实 WebSocket 会话准入验证，文本模型通过 HTTP 请求验证，并在设置页逐项显示结果。
- 将 Qwen3.5 Omni 系列置于听写模型列表首位，其中 Plus 排在 Flash 之前。
- 更新发布文档，说明运行时更新渠道切换与独立 Sparkle feed 的映射关系。

本版延续 0.5.0a2 的 macOS 主线程粘贴修复、Rust 后端和回退边界。GPL-3.0-only 许可保持不变。
