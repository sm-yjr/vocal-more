# Vocal More 0.6.1+2

本版修复 0.6.0 听写流程中的桌面同步等待，面向 macOS 14 及以上的 Apple Silicon Mac。

## 变更

- 兼容粘贴的 50 ms 稳定等待改为异步事务，等待期间主线程可以继续响应快捷键、取消和胶囊动画；保留顺序、剪贴板所有权检查及恢复保护。
- 可选词典学习读取目标应用的总等待预算收紧至 150 ms。超时跳过当次学习并继续提交结果，不更改用户的学习设置。
- 听写状态更新只刷新菜单状态，避免反复重建完整菜单和重新配置快捷键。
- 在听写、结果提交和剪贴板清理期间保持应用活动，空闲后释放；增加默认关闭、仅记录固定阶段耗时的诊断指标。

## 验证范围

已完成自动回归、离线夹具对照和构建检查。用户明确跳过本次真实桌面、麦克风及在线端到端测试，实际 Fn 启动与跨应用输出效果尚未验证。本版没有更改模型，也不声称云端识别提速。局部数据及复现方式见 [延迟诊断记录](../dictation-latency-0.6.0-2026-10-09.md)。

本版为 stable，版本与构建号为 0.6.1+2。
