# Vocal More 0.7.1-beta.1+6

本版为 Beta 预览版，聚焦**听写准确率、低声抗噪与双语保真**三项核心能力升级，适用于 macOS 14 及以上的 Apple Silicon Mac。

## 变更

- **双轨听写模型与多语种防翻译升级**：
  - 接入百炼最新 `qwen-audio-3.1-asr-flash-message`（设为默认实时模型）、`qwen-audio-3.1-asr-flash-streaming`、`qwen-audio-3.1-asr-flash`（默认短音频离线降级）、`qwen-audio-3.1-realtime-plus` / `flash` 及 `qwen3.8-flash`（默认润色模型）/ `qwen3.8-max`，并更新北京区官方计费快照。
  - 实现 `hybrid_asr` 双轨路由：默认日常听写直走 `qwen-audio-3.1-asr-flash-message` 原生口语顺滑（`disfluency_removal_enabled`）单级直出以降低延迟；开启高级润色强度、结构化输出、翻译或 AI 提示词模式时自动级联二级文本润色模型；开启「看屏幕说话」时继续自动路由至 `qwen3.8-omni-flash-realtime`。
  - 修复双语听写润色 Prompt 的中文偏置，强化原语种保真约束，避免纯英文或中英混说被静默翻译为中文。
- **听写前光标语境、动态超级热词与跨轮短记忆**：
  - 新增默认开启的「光标语境与动态热词」能力（`cursor_context_enabled`，密码/安全输入框与隐私黑名单应用严格 fail-closed）：听写启动时并发采集聚焦应用、窗口标题、选中文本及光标前后语境，零阻塞热启动录音；若采集晚于握手返回则通过 `continue-task` 会话中热更新上下文。
  - 自动提取光标附近的代码与技术标识符，与个人词典共同通过 3.1 ASR 超级热词（`weight=50`）增强识别；同时保留同应用 5 分钟内最近 3 轮听写记录写入多轮 `input.context`。
- **低声 DSP 管线升级与松手尾音缓冲**：
  - 原生音频引擎将 1 阶 RC 高通升级为 4 阶 Butterworth 级联双二阶高通（-24 dB/oct 滚降），更彻底抑制空调、风扇等低频底噪，并接入低声柔和动态压缩与软拐点峰值限幅，放大气声的同时抑制喷麦失真。
  - 新增可配置松手尾音缓冲（`audio.tail_padding_ms`，默认 `200` ms，可在设置页调整），减少松开热键截断尾字的现象，取消听写时立即撤销。

## 验证范围

已完成原生音频库编译（`-Wall -Wextra -Werror`）、Rust 全工作区测试（含 GPUI Kit `settings_rendering` 渲染测试与协议/双轨/跨轮语境集成测试）、Python 全量回归测试（含 4 阶 Butterworth 频响与低声 DRC 实测）以及前端基线检查。

本版为 beta 预发布版（`sparkle:channel=beta`），版本与构建号为 0.7.1-beta.1+6，不影响 `v0.7.0` 稳定版 Latest。
