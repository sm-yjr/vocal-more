# Vocal More 0.4.15

本版本改进麦克风启动失败时的反馈和恢复流程。启动超时、上一次音频任务仍在结束或麦克风暂时无响应时，浮动胶囊会保留清晰提示，并在可以再次尝试时提醒用户手动按听写键；应用不会自动重复已经取消的听写。若系统音频调用长期无响应，仍需重启应用恢复。正常首次连接保持简洁，普通状态也不会被错误清除。

设置页更简洁。润色页保留输入用途、输出语言、强度、结构、语气、人设和自定义提示，移除需要额外理解的模型、温度和思考选项。词典页保留自动学习开关、排除 App 和自定义词条；高置信度纠正会自动加入词典，其他词条可以手动添加，旧的自动学习记录和审核入口不再展示。

本版本同步更新并发运行时文档和取消后的测试行为。

GPL-3.0-only 许可保持不变。
