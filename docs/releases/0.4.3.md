# Vocal More 0.4.3

## 提示词输入用途

设置中的“输出类型”升级为“输入用途”。选择 **Agent 提示词** 后，普通按住说话或长语音输入会保留原来的录音手势，但本次会话会作为独立的 Prompt 输入意图处理。

口述内容会按照结果优先的方式整理为可直接发送给 Agent 的 Prompt：

- `Goal` 始终写清最终目标；
- `Context`、`Output`、`Boundaries` 只在确实会改变结果时加入；
- 阻塞执行且无法安全假设的信息进入 `Open questions`；
- 不再强制生成 Role、Success criteria、Constraints、Stop rules 等固定空壳小节；
- 不补充用户没有口述的业务事实、偏好、数据或技术结论。

## 录音中的提示词教练

提示词输入时，悬浮胶囊会根据已经识别到的内容，只提醒当前最值得补充的一项，例如：

- 先说明希望 Agent 完成什么；
- 补充交付形式或验收标准；
- 补充版本、兼容性、预算或禁用项等关键边界；
- 补充会改变答案的必要背景。

完整性判断完全在本地用确定性规则完成，不会为提醒功能新增模型请求，也不会保存局部转写内容。ASR 尚未返回局部文本时，胶囊显示通用的 Goal 提示。

## 运行时行为

- 长语音模式会把配置为 Prompt 的普通听写提升为会话级 `PROMPT` 意图。
- Prompt 会话禁用边录边粘贴，避免先写入原始转写、结束时再写入结构化 Prompt。
- 按住说话与长语音的触发手势保持不变；会议模式和指令模式不受影响。
- macOS 与 Windows 胶囊都支持 Prompt 标签和完整性提醒。
- 现有 `llm.polish_mode: prompt` 配置继续兼容，无需迁移。

提示词结构参考 ChatGPT Prompting 指南：
https://learn.chatgpt.com/docs/prompting
