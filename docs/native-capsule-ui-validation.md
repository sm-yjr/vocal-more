# 原生胶囊布局与刷新验证

2026-09-05，针对工作区 0.4.10 原生胶囊实现进行检查。

英文会议录音标签实际需要 110pt，此前仅分配 76pt；英文逐字稿和会议纪要
阶段分别需要 128.5pt、118pt，此前处理标签固定为 112pt。现在按原生字体
测量结果分配宽度，并给按钮保留间距。透明窗口宽度增加至 240pt/400pt，
容纳本地化内容和阴影；展开的黑色表面仍为 360pt。

流式文本使用 NSTextView 和 NSScrollView，按宽度换行并跟随最新输出，
按 UTF-16 范围处理 emoji。最多布局最近 4000 个字符。同一段文字不重复
更新，窗口尺寸不变时不再请求原生窗口重绘，文字更新不重复布局全部控件。

波形柱改为 CALayer，禁用逐帧几何更新的隐式动画，按屏幕像素取整，
高度不变时跳过写入。24 柱、3000 次连续调用的同机微基准：原实现约
0.104ms/次，修改后约 0.042–0.048ms/次。这仅代表同步调用开销，不能
推导完整录音过程的 CPU、GPU、帧率或功耗。处理进度接近 90% 后停止
60Hz 定时器；隐藏状态拒绝后续文本/状态更新，新录音清除旧波形和阶段。

显隐使用表面透明度，避免 NSView 隐藏后跨尺寸切换时的 backing store
裁切。隐藏前停止刷新、允许鼠标穿透，立即移除可见表面，保留原有延迟
orderOut 生命周期。

运行 `uv run python scripts/check_native_capsule.py` 可检查真实 AppKit
对象，覆盖中英文、六种模式、紧凑/展开共 24 组布局，按钮回调、长文本
滚动、处理标签、进度收敛和再次录音状态重置。该检查已接入 macOS pytest
子进程，避开常规测试的 AppKit mock。

加 `--snapshot-dir /tmp/vocal-capsule-snapshots` 会短暂显示独立测试窗口，
导出原生视图 PNG，供检查实际文字、按钮和边界。本次复查了英文指令、
展开 Prompt 和长文本画面。脚本不会启动音频采集、ASR 或访问网络。

本次没有替换已安装的应用或发布版本，也未测量完整录音链路的持续帧率。
