# 后端功能边界

2026-09-07 起，产品保留按住说话和实时长听写两种录音交互。用户在设置中手动选择普通听写润色或 Prompt 整理；不再按前台 App 自动切换输出方式。

会议模式、会议逐字稿与纪要生成、语音指令模式（直接回答或执行口述任务）、App 分类与类别计数均已移除。删除范围包括独立服务、启动装配、专用任务执行器、快捷键、RPC／WebView 操作、配置字段，以及 macOS 和 Windows 的入口。会议和语音指令专用的离线系统提示词／联网搜索分支也已删除。

启动装配只创建 `WalkieTalkieMode` 和 `RealtimeLongMode`。两者共享 `DictationWorkflow`，录音重试由独立的 `RecordingRetryRuntime` 负责。录音仓库只负责持久化，不再提供会议任务的状态变更接口。`DictationCommandCoordinator` 继续串行处理开始、停止、取消等控制操作；它属于录音并发机制。

## 旧数据处理

加载旧配置时，`default_mode: meeting` 回退为 `realtime_long`。`context_personalization` 和 `hotkey.command_key` 被忽略，后续保存不再输出。手动选择的 `llm.polish_mode` 继续保留，旧指令键不会被转成普通听写键。

已有录音、转写、会议纪要和指令结果的元数据不删除。历史页可继续只读显示已有纪要，播放、复制、重新转写和删除录音的通用操作保留；生成新纪要的入口和后端请求已移除。旧的 `context-profile.json` 不再读取或更新，本次代码改动不会删除用户目录中的文件。

ASR 的原生热词、词典别名替换、手动润色规则和底层供应商上下文参数保持独立。底层可接受显式上下文不代表会读取前台 App，应用层已无 App 分类服务。语音指令模式的删除不影响按系统提示词进行听写润色。

## 验证范围

回归覆盖旧配置迁移、废弃 API 拒绝、快捷键迁移、已有历史数据保留、普通录音启动与取消、重试、手动 Prompt 选择和设置页入口。运行完整 Python 测试、前端测试、类型检查和设置资源构建；不构建本地 DMG。
